What this guide covers

This dashboard is built for the Lingango pack and currently covers Minecraft Java 1.20.1 admin commands plus verified command sets from Forge, FTB Essentials, FTB Chunks, FTB Teams, FTB Quests, Waystones, KubeJS and spark. Not every one of the 466 installed mods exposes chat commands.

If the live server tab-completion disagrees with this guide, trust the server — configs and custom KubeJS scripts can change what is registered.
