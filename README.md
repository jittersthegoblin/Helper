# 🐸 Lingango Admin Helper

A clickable command dashboard for the Lingango Minecraft server.

Built for the current server pack:

- Minecraft Java 1.20.1
- Forge 47.4.20
- 466 mods
- Vanilla + Forge + FTB Essentials + FTB Chunks + FTB Teams + FTB Quests + Waystones + KubeJS + spark

## Features

- Searchable command cards
- Category filters
- Favorites stored in the browser
- One-click copying
- Edit & Copy for placeholders such as `<player>` and `<x y z>`
- Routine / Caution / Danger labels
- Quick admin actions
- Dark/light theme
- Mobile-friendly layout

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save.

The live Minecraft server is the final authority because configs and custom scripts can alter registered commands. Use Tab completion when a mod command needs IDs, players, dimensions, teams, or other arguments.

Before destructive operations, use `/save-all flush` and make sure backups are healthy.
